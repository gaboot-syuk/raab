# Panduan Pengguna

Panduan ini ditulis untuk orang yang **memakai** situs, bukan yang membangunnya.
Isinya urutan langkah untuk pekerjaan nyata, plus hal-hal yang paling sering
salah — bukan daftar fitur.

| Berkas | Untuk siapa |
|---|---|
| `sekretaris.md` | Sekretaris — keanggotaan, kegiatan, presensi, arsip, aspirasi, laporan |
| `bendahara.md` | Bendahara — buku kas, iuran, anggaran, hibah, laporan keuangan |
| `konten-manager.md` | Konten Manager — publikasi, halaman, media, galeri, prestasi |
| `kader.md` | Kader — kartu, RSVP, presensi, poin, prestasi, pustaka, iuran, karya |
| `deploy.md` | Pengelola server — pemasangan, penjadwal, cadangan, pembaruan |

## Peran lain

**Superadmin** tidak punya panduan tersendiri karena cakupannya adalah
gabungan seluruh peran di atas, ditambah tiga hal yang hanya bisa dilakukan
Superadmin:

1. **Panel → Cadangan Basis Data** — berkasnya memuat SELURUH isi basis data
   termasuk data pribadi anggota dan hash kata sandi, sehingga tidak diberikan
   kepada peran lain.
2. **Panel → Diagnostik** — keadaan teknis: basis data, antrean, email,
   cadangan, penjadwal, dan galat hari ini. Tidak ada kata sandi atau kunci
   rahasia yang ditampilkan di sana.
3. **Pengguna & Peran** — mengelola akun pengurus dan hak aksesnya.

## Cara membaca panduan ini

Setiap panduan punya bagian **"hal yang sering salah"**. Bacalah bagian itu
lebih dulu bila baru pertama kali memakai. Sebagian besar pertanyaan yang
datang ke pengurus berasal dari lima hal yang sama.
